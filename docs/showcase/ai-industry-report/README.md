# AI Industry Report

A 9-page executive-style report generated for the public Presentation Studio showcase. The narrative uses clearly labeled illustrative demo data; it is not current-market research.

## Outputs

- [PPTX](ai-industry-report.pptx) — native editable text, shapes, and charts
- [HTML](ai-industry-report.html) — offline, fixed 16:9, keyboard-navigable companion
- [PDF](ai-industry-report.pdf) — browser-rendered, print-ready preview
- [Prompt](prompt.md) · [Manifest](manifest.json) · [Illustrative data](illustrative-data.json)
- [Preview](preview.png) — selected pages for repository display

## Route and editability

`ppt-master → native-editable-deck` for the PPTX output. The HTML companion is generated from the same narrative and is suitable for browser viewing and PDF export; it does not claim native PowerPoint editability.

## Verification boundary

Native package structure and object types are inspected locally. Visual previews are rendered from the companion HTML because this environment has no PowerPoint/LibreOffice desktop renderer; that limitation is recorded rather than hidden.
