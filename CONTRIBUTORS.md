# Contributors / 贡献者

Presentation Studio is an integration and orchestration layer built on four upstream projects. The people below are credited as the original authors or maintainers of those upstream works; this file does not rewrite Git commit authorship.

Presentation Studio 是基于四个上游项目构建的整合与编排层。以下人员以原项目作者或维护者身份署名；本文件不会改写 Git 提交的真实作者信息。

## How to contribute / 如何贡献

Contributions should preserve upstream attribution, license files, and the exact source revisions recorded in `presentation-studio/source-lock.json`. When modifying a vendored engine, identify the upstream source and clearly separate local integration changes from upstream code.

任何贡献都必须保留上游署名、许可证文件以及 `presentation-studio/source-lock.json` 中记录的精确来源版本。修改内置引擎时，应注明上游来源，并明确区分本地整合改动与上游代码。
